

# Wander - Luxury Photographer Portfolio (Dubai)

A high-end, cinematic photography portfolio inspired by aleksandramandic.com — monochrome aesthetic, editorial layout, and smooth animations.

---

## Design System
- **Colors**: Deep black (#000/#0A0A0A) backgrounds, crisp white text, subtle gray accents
- **Typography**: Playfair Display (italic/cursive) for headings & accents, Inter for body text
- **Animations**: Framer Motion fade-ins, parallax scroll effects, smooth hover transitions
- **Vibe**: Minimalist, luxury, editorial, cinematic

---

## Global Navigation
- Sticky transparent header with "WANDER" logo (left) in elegant type
- Right-side links: Home, About, Contact, and Portfolio dropdown
- Portfolio dropdown on hover reveals 7 categories: Automotive, Events, Sports, Portraits, Lifestyle, Product, Real Estate
- Mobile: hamburger menu with full-screen overlay

---

## Pages (10 Total)

### 1. Home Page
- Full-viewport hero with video placeholder background, bold cursive headline overlay ("Capturing Moments in Dubai"), and CTA button
- "About Us" teaser — split layout with large B&W image and brief intro text
- "Services" grid — clean cards for key photography categories
- Footer with contact details, social links (Instagram, YouTube, etc.), and copyright

### 2. About Page
- Storytelling section with large cinematic imagery and the Wander brand story
- Stylized FAQ accordion section (black/white themed)
- Bold CTA banner for booking inquiries

### 3. Contact Page
- Minimalist contact form (Name, Email, Subject, Message) with validation
- Direct email link and Dubai address/phone details
- Clean, centered layout with lots of whitespace

### 4. Portfolio Overview Page
- 7 large hover-reactive category cards in a grid
- Each card shows category name with elegant typography overlay
- Hover effect: subtle zoom/brightness shift on the image
- Links to individual category pages

### 5–11. Individual Category Pages (7 Pages — Reusable Template)
- **Portraits & Product**: Masonry-style image gallery layout
- **Automotive, Events, Sports, Lifestyle, Real Estate**: Image grid + embedded video placeholders
- Each page has a category title hero section and back-to-portfolio navigation
- Lazy-loaded images with blur-up placeholder effect

---

## Technical Highlights
- Framer Motion for all scroll-triggered fade-ins and parallax effects
- Lazy loading with blur placeholders for all images
- Fully responsive — mobile-first typography and layout scaling
- Placeholder images from Unsplash for each category
- Video placeholder sections using styled div containers (ready for real video embeds)
